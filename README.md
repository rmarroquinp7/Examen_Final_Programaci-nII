# Fotos App

**Estudiante:** Rosbelyn Alexandra Marroquín Portillo 0907-25-13464

## Descripción
Aplicación móvil hecha con React Native, Expo y TypeScript. El usuario inicia
sesión con correo y contraseña. Con sesión activa puede elegir
una fotografía de la galería o tomarla con la cámara, verla en pantalla,
cambiarla, eliminarla de la vista previa y cerrar sesión. La sesión se
mantiene al cerrar y reabrir la app.

## Instalación y ejecución
1. Clonar el repositorio: `git clone https://github.com/rmarroquinp7/Examen_Final_Programaci-nII`
2. Entrar a la carpeta: `cd fotos-app`
3. Instalar dependencias: `npm install`
4. Ejecutar: `npx expo start` y escanear el QR con Expo Go.

## Dependencias principales
